Backend

Where this device syncs its inventory data. Demo keeps everything on this device only.

Settings — including the Access Key — are stored only in this device's browser (localStorage). They are never in the code or the GitHub repo. Get the key in AppSheet: Manage → Integrations → “IN: from cloud services to your app” → AppSheet API.

Paste the Web app link from Deploy (ends in /exec). If the script has a TOKEN set at the top, type the same token here — it must match exactly. If the script's TOKEN is blank, leave this blank. Both are stored only in this device's browser. Anyone who has the link (and token, if set) can read and write this inventory, so keep them among the people using it. Setup steps: SETUP.md → Option B.
